# MeterNest Homebrew Tap

Install MeterNest on an Apple silicon Mac using Homebrew.

```sh
brew install --cask mishkang/tap/meternest
```

The cask downloads the DMG from [MeterNest Releases](https://github.com/mishkang/MeterNest/releases). The current build uses an ad-hoc signature and has not been notarized by Apple.

To upgrade an installation made through this tap:

```sh
brew update
brew upgrade --cask mishkang/tap/meternest
```
